# 12주차 인터랙티브반 공통 실습 파일

## 목적
VS Code의 GitHub Copilot Agent를 이용하여 **이미 만들어진 웹페이지에 기능을 추가**하고, 수정 내용을 확인한 후 GitHub Pages로 배포한다.

## 파일 구조
- `index.html`: 페이지 구조
- `css/style.css`: 페이지 디자인 및 반응형 스타일
- `js/script.js`: 페이지 진입 효과 + 연도 선택에 따른 콘텐츠 전환
- `images/year-a.jpg`, `images/year-b.jpg`: 가상 실업률 그래프 (실제 통계 아님)

## 시작 상태
- 웹페이지와 연도 A의 수치·설명·그래프가 표시된다.
- 페이지 진입 시 히어로 수치가 0%에서 4.2%로 올라가고 막대가 함께 성장한다.
- 스크롤 시 섹션이 등장하는 효과는 작동한다.
- 연도 A/B 버튼을 선택하면 해당 연도의 가상 수치·설명·그래프가 표시된다.

## 검증
1. 페이지를 열면 히어로 수치가 0%에서 4.2%로 바뀌고 막대가 올라간다.
2. 처음에는 연도 A가 표시된다.
3. 연도 B를 클릭하면 수치·제목·설명·그래프가 모두 B로 전환된다.
4. A를 다시 클릭하면 A로 복원된다.
5. 선택된 버튼만 활성화되고 `aria-pressed="true"`로 표시된다.
6. 페이지의 다른 섹션과 스크롤 등장 효과는 유지된다.
7. GitHub Pages에 게시한 주소에서도 동일하게 작동한다.

## GitHub Pages 배포
1. VS Code에서 폴더를 열고 브라우저로 `index.html`을 실행한다.
2. GitHub 저장소를 만들어 이 폴더의 파일을 저장소 **루트**에 업로드한다.
3. 저장소 `Settings > Pages`에서 `Deploy from a branch`, `main`, `/(root)`를 선택한다.
4. 제공되는 Pages URL로 접속해 이미지·스타일·버튼이 제대로 표시되는지 확인한다.

> 그래프와 수치는 학습용 가상 데이터이며 실제 실업률 통계가 아니다.
